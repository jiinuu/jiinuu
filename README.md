## Hi, I'm Jinwoo Park

**I build with data and AI to make everyday tasks easier.**

My projects include tools that automate repetitive work and AI systems that answer questions using documents. I care about both how a tool works and whether someone can understand and use it for the first time.

### What I work on

- **AI and document retrieval** — RAG systems that help people find information and check the sources behind an answer.
- **Workflow automation** — tools for recurring tasks such as organizing files, collecting updates, and sending notifications.
- **Usable products** — interfaces that reduce unnecessary choices and steps while making data and limitations clear.

### Selected projects

| Project | What it does |
| :--- | :--- |
| [LeanRAG](https://github.com/jiinuu/LeanRAG) | A PDF-based RAG experiment that retrieves relevant passages and returns answers with source references. Supports Gemini and LM Studio. |
| [Folder Organizer Agent](https://github.com/jiinuu/FolderOrganizerAgent) | A desktop tool for organizing files through folder selection or drag-and-drop, with a dry-run option before moving files. |
| [GitTraffic](https://github.com/jiinuu/git_traffic) | A dashboard for viewing GitHub repository traffic and clone trends in one place. |
| [Trend Alert Bot](https://github.com/jiinuu/trend-alert-bot) | A bot that collects AI updates from RSS feeds and delivers them through KakaoTalk's “send to me” feature. |
| [Build Minimal Decision UX](https://github.com/jiinuu/build-minimal-decision-ux) | A Codex skill for designing and reviewing interfaces with fewer decisions and steps to complete a task. |
| [Text Menu Calorie Estimator](https://github.com/jiinuu/text-menu-calorie-estimator) | Estimates calories from menu names and explicit ingredient and portion assumptions. Outputs are estimates, not measured values; unreviewed menus are flagged for review. |

See each repository's README for setup instructions and usage requirements.
