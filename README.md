### English

I look at data and try products firsthand to understand where people run into difficulties.
I'm interested in turning those findings into easy-to-use tools with AI and automation.

- [Folder Organizer Agent](https://github.com/jiinuu/FolderOrganizerAgent) — A drag-and-drop tool for organizing files
